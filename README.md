# Agents Playground

Welcome to **Agent Playground**! This is a simple, hands-on repository dedicated to building small AI agents from scratch and progressively upgrading them from basic architectures to more complex, production-grade patterns.

---

## 🎯 Purpose & Philosophy

The goal of this project is to learn agentic systems by doing:
- **Start Simple:** Begin with minimal LLM calls and basic tool-use primitives.
- **Incremental Upgrades:** Step-by-step evolution—adding memory, structured routing, graph-based workflows, and multi-agent systems.
- **Hands-On & Educational:** Clear, self-contained scripts designed to experiment with agent concepts in real time.

---

## 🚀 Roadmap / Progression

```
[Level 1: Minimal Agent]
        │
        ▼
[Level 2: Tool-Calling Agent]
        │
        ▼
[Level 3: RAG & Vector Memory]
        │
        ▼
[Level 4: LangGraph State Machine]
        │
        ▼
[Level 5: Multi-Agent Collaboration]
```

1. **Level 1 — Basic Prompt Loop:** Single LLM call with dynamic input/output.
2. **Level 2 — Single-Tool Calling:** Integrating external tools (e.g., search, calculators).
3. **Level 3 — Memory & Retrieval:** Persistent conversation context and vector DB integration (RAG).
4. **Level 4 — Graph Orchestration:** State machines with conditional routing and retry logic (e.g., LangGraph).
5. **Level 5 — Multi-Agent Systems:** Specialized agents delegating tasks and collaborating.
